# Nitro Battle Royale v0.3 (Godot 4.3)
O projeto Godot fica na pasta godot/. Os arquivos Unity anteriores permanecem preservados.

Protótipo offline: arena de caixas, câmera em terceira pessoa, movimentação, salto e raycast de tiro sem dano.
**Ainda não inclui multiplayer online, armas completas ou mapa Bermuda.**

O workflow `.github/workflows/godot-android.yml` tenta exportar um APK de depuração em GitHub Actions.
Abra Actions > Godot Android APK para acompanhar. Se o job falhar, verifique logs e dependências de exportação Android.

Apenas publique modelos, mapas ou texturas quando possuir licença de redistribuição.
